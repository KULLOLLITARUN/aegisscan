# AegisScan

Hosted AegisScan: upload a folder or enter a public Git URL and get a security and optimization
scan (Bandit, Semgrep and built-in secret scanning). Access needs the token set in this Space's
secrets (`AEGISSCAN_ACCESS_TOKEN`).

Source and documentation: https://github.com/KULLOLLITARUN/aegisscan
